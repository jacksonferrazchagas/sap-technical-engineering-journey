# Initial KPIs

| KPI | Description |
|---|---|
| Total Production Quantity | Total quantity produced during the selected period |
| Material Cost | Total direct material cost |
| Labor Cost | Total direct labor cost |
| Total Production Cost | Material cost plus labor cost |
| Cost per Unit | Total production cost divided by production quantity |
| Production Efficiency | Actual output compared with planned output |
| Cost Variance | Actual cost minus planned cost |
